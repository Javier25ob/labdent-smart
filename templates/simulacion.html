Cómo funciona el modelo
  • Las órdenes llegan al azar (proceso de Poisson): en promedio {{ p.llegadas }} por día de {{ jornada // 60 }} horas, es decir una cada {{ '%.0f'|format(jornada / p.llegadas) }} min.
  • El tiempo en cada estación es aleatorio (exponencial) alrededor del promedio que indicas. Cada estación tiene una sola fila; el horno se modela con su tiempo equivalente por orden.
  • Se simulan {{ p.dias }} días repetidos {{ p.replicas }} veces con semillas distintas y se promedia; el «±» es el intervalo de confianza del 95%. Se descartan los primeros {{ calentamiento }} días, en que el laboratorio arranca vacío. A y B usan las mismas semillas, para que la comparación sea justa.
  • «Espera teórica» sale de la fórmula de colas M/M/c (Erlang C). Si coincide con la simulada, el modelo está bien construido; en estaciones muy cargadas (>85%) la simulación varía más entre repeticiones.
  • La simulación es una herramienta de decisión: no usa tus órdenes registradas sino el ritmo que escribas arriba.
